# Franco Badinas Portfolio

A customizable static portfolio for graphic design and short-form video editing.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Customize

- Replace the Unsplash URLs in `index.html` and `script.js` with your project images.
- Update contact details in `contact.html`.
- Change colors at the top of `style.css`.
- Replace the Formspree placeholder in `contact.html` with your form endpoint.

## Deploy

Enable GitHub Pages in repository Settings → Pages, choose the `main` branch and `/ (root)` folder.
